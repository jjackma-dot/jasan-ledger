금융손익
—만원
—
손익기준 시트의 항목별 매입금액 대비 현재 평가액. 부동산은 여기 포함하지 않습니다.

항목별 손익

기준값

환차손익 = (미국주식 매입금액 + 달러예수금) × (현재환율 − 매입 평균환율). 무매·VR 손익은 달러 기준으로 계산해 현재 환율로 환산하므로, 환율 영향이 이 항목 하나로 분리됩니다.

확인 필요한 알림

자동으로 읽지 못한 알림입니다. 확인하고 입력을 누르면 아래 붙여넣기 칸에 원문이 채워집니다. 관계없는 알림이면 무시를 누르세요.

최근 자동 반영

체결 알림이 오면 조건에 맞을 때 여기 조용히 반영됩니다. 이 목록에 없으면 아직 안 들어온 것입니다.

알림톡 붙여넣기

오늘 시세

시세 공급자

키가 없으면 무료 공개 소스를 순서대로 시도합니다. 조회에 실패한 항목은 전일 값을 임시로 쓰고 임시 표시가 붙으며, 이후 조회에 성공하면 자동으로 덮어씁니다. 직접 입력한 값은 그날 하루 동안 덮어쓰지 않습니다.

보유 현황

서버 연결

연결하면 알림수집 앱이 보낸 체결 내역과 시세를 자동으로 받아옵니다. 기기 여러 대에서 같은 기록을 보게 됩니다.

입출금

입출금은 수익에 영향을 주지 않습니다. 금융자산과 기준원금이 같은 폭으로 움직이므로 누적수익은 그대로입니다. 수익금 자체를 바로잡으려면 실적/계획 탭의 기준원금을 직접 고치세요.
