# 자산 원장 — 배포본

매일 자산을 누적 관리하는 개인용 웹앱입니다. 여기는 **배포 전용 저장소**입니다.

→ **https://jjackma-dot.github.io/jasan-ledger/**

```
web/       설치형 웹앱 (PWA) — 이 저장소에 있는 건 이게 전부입니다
```

## 왜 저장소가 따로 있나

빌드 원본·설계 문서·안드로이드 수집 앱은 비공개 저장소 `jasan-ledger-private` 에 있습니다.
거기에는 부동산·자녀 실명과 실제 자산 금액이 들어 있어 공개할 수 없습니다.

이 저장소가 공개인 이유는 하나뿐입니다 — **무료 GitHub 계정은 공개 저장소에서만 Pages 를
배포**합니다. 그래서 개인정보가 하나도 없는 `web/` 생성물만 여기로 내보냅니다.

`web/index.html` 은 생성물이라 여기서 고치지 않습니다. 비공개 저장소에서 `src/` 를 고쳐
다시 빌드한 뒤 `tools/publish.sh` 로 내보냅니다.

## 여기 올라온 것에 개인정보가 없다는 근거

`web/index.html` 의 `SEED` 는 비어 있고 `PLAN_BASE` 는 전부 0 입니다. 부동산 이름은
"부동산 A/B" 로 나가고, 실제 값은 로그인 후 Supabase 에서 받아옵니다. 내보내기 전에
`publish.sh` 가 실명·금액 검사를 돌려 하나라도 걸리면 배포를 중단합니다.

## 설치

폰 크롬으로 위 주소를 열고 **⋮ › 앱 설치** 를 누르면 아이콘이 생깁니다.
앱 안 **입력 › 서버 연결** 에 Supabase 주소·공개 키·계정을 넣으면 연결됩니다.
